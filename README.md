# KIK-IRPA CPP

Pipeline de stitching d'images en C++17, avec une implémentation de corrélation
de phase pour l'appariement de tuiles.

## État de compilation

Les 22 fichiers `.cpp` du projet ont été vérifiés avec succès en compilation
syntaxique C++17 à l'aide de GCC 16.2 (sur les 22 files, aucun n'a failed)
